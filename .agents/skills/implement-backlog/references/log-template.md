# Run log template — unattended adapter

`.agent-runs/<run-id>/run-log.md`; one run directory per issue/task.
All machine-readable state and evidence for the same run lives beside this log.

- issue/claim · typed branch · policy profile
- Phase 0–1: authority, baseline, proven delta or corroborated no-change
- Phase 2 — ambiguity/assumption blocker and posted evidence when applicable
- Phase 3 — mechanically validated plan, scope, evidence and mutation target; APPROVAL-FINGERPRINT
- Phase 4–5: owner implementation and deterministic evidence
- Phase 6 — durable sync and owner checkpoint SHA
- Phase 7 — General Code Reviewer commit/report + owner inspection decision
- Phase 8 — Mutation Hardener commit/report + coverage/mutant summary + owner inspection decision
- Phase 9 — Owner acceptance and final SHA/diff/evidence
- Phase 10 — delivery, external reviews pending/listed, terminal
- attempts/non-progress blockers · claim release/park · Cost
