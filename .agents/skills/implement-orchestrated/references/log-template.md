# Run log template — orchestrated-worker adapter

`.agent-runs/<run-id>/run-log.md`; one run directory per issue/task.
All machine-readable state and evidence for the same run lives beside this log.

- run id · issue · branch · mode · claim
- Phase 0–1: spec relevance, baseline, proven delta/no-change corroboration
- Phase 2 — assumptions/questions and upstream blocker state
- Phase 3 — approval bundle/fingerprint and assisted approval or autonomous mechanical validation
- Phase 4–5: owner implementation and evidence
- Phase 6 — durable sync and checkpoint SHA
- Phase 7 — General Code Reviewer handoff and owner acceptance
- Phase 8 — Mutation Hardener handoff, target 100% report and owner acceptance
- Phase 9 — Owner acceptance and final candidate/evidence
- Phase 10 — delivery; external orchestrator/pipeline reviews pending/listed; terminal
- re-engagements · Cost
